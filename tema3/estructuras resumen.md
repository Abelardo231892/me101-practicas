**Resumen de Equivalencias Estructurales: Python vs R**



* **Array de NumPy (ndarray) - Vector en R (c())**: Estructuras homogéneas empleadas para almacenar colecciones de datos del mismo tipo y realizar operaciones vectorizadas sin necesidad de bucles.
* **DataFrame de Pandas - tibble en R (tidyverse)**: Estructuras bidimensionales y heterogéneas utilizadas para manejar datos tabulares con filas y columnas etiquetadas.
* **Indexación base 0 (\[0]) - Indexación base 1 (\[1])**: Mecanismos para acceder al primer elemento de una estructura secuencial.
* **Filtro con operador relacional y lógico (df\[(cond1) \& (cond2)]) - Función filter() (filter(cond1 \& cond2))**: Métodos para realizar filtrados condicionales combinando múltiples criterios booleanos sobre tablas de datos.
